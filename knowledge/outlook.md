# Outlook ja sähköposti

## Outlook ei käynnisty tai kaatuu
1. Sulje Outlook kokonaan (Tehtävienhallinta → lopeta OUTLOOK.EXE).
2. Käynnistä vikasietotilassa: Win+R → `outlook.exe /safe`. Jos toimii, vika on todennäköisesti apuohjelmassa: Tiedosto → Asetukset → Apuohjelmat → COM-apuohjelmat → poista apuohjelmat käytöstä yksi kerrallaan.
3. Korjaa Office: Asetukset → Sovellukset → Microsoft 365 → Muokkaa → Pikakorjaus (tai Online-korjaus).
4. Luo uusi Outlook-profiili: Ohjauspaneeli → Mail (Microsoft Outlook) → Näytä profiilit → Lisää.

## Sähköpostit eivät lähde tai saavu
- Tarkista Lähtevät-kansio: jumiin jäänyt viesti, jossa on liian suuri liite (yli 20–25 Mt), estää muiden lähettämisen. Poista tai siirrä se luonnoksiin.
- Tarkista, onko Outlook "Työskentele offline-tilassa" (Lähetä/vastaanota-välilehti).
- Tarkista postilaatikon tila: täysi postilaatikko estää viestien vastaanoton. Tyhjennä Poistetut ja Roskaposti.
- Kokeile Outlookia selaimessa (outlook.office.com). Jos se toimii, vika on työpöytäsovelluksessa.

## Outlook kysyy salasanaa jatkuvasti
Poista tallennetut tunnistetiedot: Ohjauspaneeli → Tunnistetietojen hallinta → Windows-tunnistetiedot → poista MicrosoftOffice- ja Outlook-alkuiset rivit. Käynnistä Outlook uudelleen ja kirjaudu. Tarkista myös, onko salasana vaihdettu äskettäin.

## Hakutoiminto ei löydä viestejä
Rakenna hakemisto uudelleen: Tiedosto → Asetukset → Haku → Indeksointiasetukset → Lisäasetukset → Muodosta uudelleen. Indeksointi voi kestää tunteja.
